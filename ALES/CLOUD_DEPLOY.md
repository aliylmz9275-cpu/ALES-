# ALES Cloud - Telefon Entegrasyonu Kurulum RehberiBu rehber, ALES'i internete acip telefonunda "sanki bir uygulamaymis gibi"kullanmani sağlar. Once **kisitlari** oku, sonra adimlari takip et.## Once oku: Bu ne yapar, ne yapmaz**Calisir (bilgisayarin kapali olsa bile):** Sohbet, 4-AI derin analiz/tartisma modu, sohbet gecmisi, freelance (Fiverr/Bionluk) tavsiye/fiyatlandirma/musteri mesaji taslagi uzmanligi.**Calismaz (fiziksel olarak imkansiz, PC'nin acik olmasini gerektirir):**Fiverr/Bionluk tarayici otomasyonu, ekran gorme, bilgisayarindaki dosyalaraerisim, yerel uygulama acma, sesli yanit (TTS su an PC hoparlorunde calar).Bunlari istedigin an ALES sana "bilgisayarindaki ALES'i kullan" diyecek.**Kalicilik:** Sohbet gecmisi sunucunun diskinde tutulur. Platform servisiyeniden baslatir/deploy ederse (guncelleme yaptiginda, veya bedavakatmanda uzun sureli aktivite sonrasi) bu veri silinebilir. Kalici birveritabani (Postgres vb.) v2 icin planlanabilir, su an YOK.\---## 1\. ADIM: Iki barindirma secenegi — hangisini secmelisin?||**Render** (onerilen varsayilan)|**Railway** (railway/ klasoru zaten hazir)||-|-|-||Kredi karti|**Gerekmiyor**|**Gerekiyor** (2023'ten beri)||Ucretsiz sure|Kalici ücretsiz katman var|Sadece 30 gun / $5 kredi, sonra $5-20/ay||Bedava katmanin bedeli|15 dakika hareketsizlikte "uyur", sonraki istekte birkac saniye "uyanma" gecikmesi olur|Uyumaz ama 30 gun sonra ucret baslar||Ne zaman mantikli|Ara sira telefon kontrolu, para harcamak istemiyorsan|Sik kullanim, uyuma gecikmesi hic istemiyorsan ve odemeye hazirsan|**Cogu kullanim icin Render'i oneririm** — Ali freelance/maliyet bilinclicalisiyor, ücretsiz kalici katman bu profile daha uygun. Asagida ikisiicin de adimlar var, istedigini sec.## 2\. ADIM: Projeyi GitHub'a yukle (her iki platform icin de gerekli)1. github.com'da ucretsiz bir hesap ac (yoksa).2. Yeni bir **private** repo olustur (orn. `ales`).3. Bilgisayarinda ALES klasorunun icinde:```   git init   git add .   git commit -m "ilk yukleme"   git branch -M main   git remote add origin https://github.com/KULLANICI\\\\\\\_ADIN/ales.git   git push -u origin main   ```(`KULLANICI\\\\\\\_ADIN` yerine kendi GitHub kullanici adini yaz.)## 3A. ADIM: Render ile deploy (onerilen)1. render.com'a git, GitHub hesabinla giris yap.2. Dashboard'da **New +** → **Web Service**.3. Az once pushladigin `ales` reposunu sec ve Connect'e tikla.4. Ayarlarda:   * **Runtime:** Docker   * **Dockerfile Path:** `Dockerfile.cloud`   * **Plan:** Free5. **Environment Variables** bolumune asagidakileri ekle (ADIM 4'tedetay var):`ALES\\\\\\\_ACCESS\\\\\\\_KEY`, `GROQ\\\\\\\_API\\\\\\\_KEY`, `CEREBRAS\\\\\\\_API\\\\\\\_KEY`, `GEMINI\\\\\\\_API\\\\\\\_KEY`,`SAMBANOVA\\\\\\\_API\\\\\\\_KEY`, `OPENROUTER\\\\\\\_API\\\\\\\_KEY`6. **Create Web Service** / **Deploy** butonuna tikla. Build 5-10 dakikasurebilir (frontend'i de derliyor). Loglari izleyebilirsin.7. Bitince sana `https://ales-xxxx.onrender.com` gibi bir adres verir —iste bu, telefonunda kullanacagin adres.*(Alternatif: repoda zaten hazir olan `render.yaml` sayesinde "New +" →**Blueprint** ile de otomatik algilatabilirsin.)*## 3B. ADIM: Railway ile deploy (alternatif)1. railway.app'e git, GitHub hesabinla giris yap (kredi karti isteyecek).2. **New Project** → **Deploy from GitHub repo** → `ales` reposunu sec.3. Proje ayarlarinda **Dockerfile Path**'i `Dockerfile.cloud` olarakayarla (repo kokunde zaten `railway.json` bunu otomatik soyleyecek).4. **Variables** sekmesinden ADIM 4'teki degiskenleri ekle.5. Deploy otomatik baslar. Bitince **Settings → Networking → GenerateDomain** ile genel bir URL al (`https://ales-xxxx.up.railway.app`).## 4\. ADIM: Ortam degiskenlerini doldur|Degisken|Ne ise yarar|Nereden alinir||-|-|-||`ALES\\\\\\\_ACCESS\\\\\\\_KEY`|Telefonundan giris sifren. **KENDIN uydur**, guclu bir sey yaz (orn. bir sifre yoneticisinden). BOS birakirsan URL'i bilen HERKES ALES'ine girebilir.|Kendin belirle||`GROQ\\\\\\\_API\\\\\\\_KEY`|Ana AI|console.groq.com||`CEREBRAS\\\\\\\_API\\\\\\\_KEY`|Yedek AI|cloud.cerebras.ai||`GEMINI\\\\\\\_API\\\\\\\_KEY`|Multi-agent "Yazar"|aistudio.google.com/apikey||`SAMBANOVA\\\\\\\_API\\\\\\\_KEY`|Multi-agent "Elestirmen"|cloud.sambanova.ai||`OPENROUTER\\\\\\\_API\\\\\\\_KEY`|Guvenlik agi yedegi|openrouter.ai|Hepsi opsiyonel ama **en az bir tanesi sart** (yoksa ALES cevap veremez).Ne kadar cogunu girersen o kadar dayanikli olur (biri limite takilirsadigeri devreye girer). Masaustu ALES'te zaten kullandigin key'lerinAYNISINI buraya da girebilirsin.## 5\. ADIM: Telefonda "uygulama" gibi kur1. Telefonunun tarayicisinda (Chrome/Safari) render/railway'in verdigiURL'i ac.2. Karsina cikan **erisim kodu** ekranina 4. adimda belirledigin`ALES\\\\\\\_ACCESS\\\\\\\_KEY` degerini gir.3. **Android (Chrome):** sag ustteki ⋮ menu → "Ana ekrana ekle" / "Uygulama yukle".**iPhone (Safari):** Paylas butonu → "Ana Ekrana Ekle".4. Artik telefonunda ALES ikonuyla, tarayici cubugu olmadan, tam ekranbir uygulama gibi aciliyor.\---## Sorun giderme* **"Sunucuya ulasilamadi" / erisim kodu ekraninda takili kaliyorsun:**Deploy loglarini kontrol et (Render/Railway dashboard → Logs), buildbasarisiz olmus olabilir.* **Ilk mesajda uzun sure bekleniyor (Render):** Bu normal — bedavakatman 15 dk hareketsizlikten sonra "uyur", ilk istekte birkac saniye"uyanma" suresi var.* **"Sunucuda hic AI API key tanimli degil" hatasi:** 4. adimdakidegiskenlerden hicbiri girilmemis, en az birini ekleyip yenidendeploy et.* **Sohbet gecmisi bir anda kayboldu:** Platform servisi yenidenbaslatti (redeploy/restart) — yukaridaki "Kalicilik" notuna bak, bubilinen bir sinirlama.
